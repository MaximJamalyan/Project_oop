# Лабораторная работа №3: Класс Matrix

## Описание
Данный проект реализует класс `Matrix` для работы с двумерными матрицами целых чисел динамического размера с обеспечением инкапсуляции и корректной работы с памятью.

## Основные возможности
- Конструирование пустых матриц (0x0), единичных квадратных матриц и прямоугольных матриц заданной размерности.
- Безопасное выделение и освобождение динамической памяти с помощью `new[]` и `delete[]`.
- Безопасный доступ к элементам матрицы с проверкой границ и генерацией исключений `std::out_of_range`.
- Заполнение матрицы с клавиатуры и случайными числами.
- Вычисление суммы всех элементов и транспонирование.
